# @macaw-ds/icons

A curated Lucide subset behind `<Icon name="check" size="md" tone="inherit" />`. Decorative by default; pass `label` when the icon carries meaning alone. The allowlist lives in `icons.config.ts`; adding an icon is a PR with a screenshot of where it is used.
