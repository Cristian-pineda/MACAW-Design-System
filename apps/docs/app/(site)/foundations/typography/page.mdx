Inter for text, Geist Mono for code. A small scale (11 to 30 px) because the audience is dense dashboards, not marketing pages. Fifteen named roles cover display, heading, body, label, caption, numeric and code; each role fixes size, leading, weight and tracking together. Type does not change with density.

Every string on screen goes through `<Text>`, so nothing else sets a font size or colour. Pick `as` for document structure (an `h2` for a section, a `label` for a field) and `variant` for the role; screen readers navigate by heading level, not by font size.
